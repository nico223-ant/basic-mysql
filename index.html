MySQL & Network Setup

Panduan basic pengelolaan database MySQL.

Part 1: Instalasi & Dasar MySQL
01
Install MySQL Server & Client
apt-get install mysql-server mysql-client
Gunakan tanda hubung (-) pada paket nama apt Debian/Ubuntu.
02
Masuk ke MySQL
mysql -u root -p
03
Melihat Database
show databases;
04
Membuat Database "sekolah"
create database sekolah;
05
Verifikasi Database
show databases;
06
Masuk ke Database "sekolah"
use sekolah;
07
Membuat Tabel "siswa"
create table siswa (nis varchar(9), nama varchar(50), kelas varchar(10), alamat varchar(100));
08
Melihat Tabel
show tables;
09
Melihat Struktur Tabel
desc siswa;
10
Mengisi Data Tabel (Insert)
insert into siswa values ('242510753', 'Alexandder', 'XII TKJ A', 'Bandung');
11
Melihat Isi Tabel
select * from siswa;
12
Keluar dari MySQL
exit;
Part 2: phpMyAdmin & Host-Only Network
13
Install phpMyAdmin
apt-get install phpmyadmin
14
Konfigurasi Network Interfaces Server
nano /etc/network/interfaces
Atur IP Static pada adapter server, contoh:
auto eth0
iface eth0 inet static
    address 192.168.10.1/24
15
Restart Service Networking
service networking restart
16
Cek IP server
ifconfig
17
Buka Network Connections Windows
ncpa.cpl
Tekan Win + R di Windows, ketik perintah di atas lalu tekan Enter.
18
Atur IP Host-Only Network di Windows
IP: 192.168.10.2 | Netmask: 255.255.255.0 | Default gateway: 192.168.10.1
Klik kanan VirtualBox Host-Only Network Adapter → Properties → Internet Protocol Version 4 (TCP/IPv4).
19
Tes Ping dari Windows (CMD) ke Server
ping 192.168.10.1
20
Akses phpMyAdmin lewat Browser Windows
192.168.10.1/phpmyadmin
Buka Browser di Windows dan masukkan URL di atas. Masukkan username dan password database kamu.
